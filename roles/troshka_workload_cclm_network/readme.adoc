= troshka_workload_cclm_network

Configures per-cluster migration networking for decentralized CNV live migration:

* `NMState` singleton (activates kubernetes-nmstate handler + NNCP CRDs)
* NNCP static IPs on the migration virtio NIC (`cclm_migration_node_ips`)
* `lm-network` macvlan NAD with whereabouts IPAM
* MetalLB pool for virt sync controller services
* Copies Troshka `troshka-ceph-external` export into nested `rook-ceph-external-cluster-details`
* External Ceph `StorageCluster` in openshift-storage

Verify `cclm_migration_parent_iface` on first live deploy (default `enp2s0`).

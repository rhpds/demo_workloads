= troshka_workload_cclm_operators

Installs CNV, MTV, ODF, Submariner, nmstate, cert-manager, and MetalLB operators on
each cluster in `cclm_target_clusters` via OLM subscriptions.

Expects the openshift-workloads `clusters` dict (`api_url` + `api_token` per cluster key).
For Troshka ad-hoc runs, pin `feat/cclm-workloads` in `requirements_content` and target
both clusters (or run once per cluster with `target_map.cluster_id`).
